# StudyCore（独立实现草案）

这个 Swift Package 只定义用户选定的 PDF 选区、摘录和笔记的数据边界。代码依据用户目标独立设计，不来自 IPA 的函数实现或资源。

- `SourceSelection` 保存文档 ID、摘录全文和有序的 `PageSelectionFragment`。片段记录从 0 开始的页索引、一个或多个页面归一化矩形，以及 PDF 文字层/OCR 来源。多个片段可覆盖多页；同一页也可有不同来源的片段。
- `StudyExcerpt` 保存选区、用户笔记和时间。更新笔记时保留来源锚点。
- `ExcerptFileStore` 是一个独立的单写入者文件存储草案，使用版本化 JSON 与原子替换保存摘录；拒绝损坏文件、未知版本、重复 ID、来源位置变更和旧笔记覆盖。它另提供最多 20 MB 的版本化摘录备份导出及原子合并恢复：新记录插入、较新笔记更新、旧记录保留，来源冲突则整批拒绝。调用方必须提供 iOS Application Support 内的文件 URL，并保证同一路径只有一个活跃写入者。
- 构造和解码都检查页索引、非空片段和矩形集合、页序、矩形范围、空文字和时间顺序；笔记更新时间不得倒退。
- 坐标原点暂定为页面左上角；PDFKit 与 OCR 的转换由相邻 `StudyApp` 草案实现，尚未在 iOS 验证。

本包自身没有 PDF 导入、文字选择、OCR、UI 或网络代码；这些入口位于相邻的 `StudyApp`。备份只包含摘录与笔记，不包含原 PDF；恢复后需重新导入相同 PDF 才能显示来源位置。文件存储和备份草案尚未编译和测试；iOS 写入源码已指定文件保护选项，应用侧设置备份排除，但属性均未在设备验证，也没有多进程写入协调。导出的 JSON 为明文，由用户主动选择保存位置。这不是经验证可运行的 iOS App，也不声称与原应用数据格式兼容。跨页片段是独立设计能力，不代表原应用已验证支持跨页选区；片段内文字与几何位置的精确对应仍需 iOS 测试。

在具备 Swift/Xcode 的环境运行 `swift test`。`.github/workflows/studycore.yml` 备有手动触发的 macOS 测试流程；它尚未上传或运行。Windows 工作机未发现 `swift` 命令，本包尚未编译或执行测试。
